## 作品：ShelfSight

視覚障害のある人がコンビニで買い物をするための Android アプリです（開発中）。現在は、店内を歩くと ARCore で自分の位置と店全体の 3D 地図を作る機能を実装しています。作った地図は端末の画面で確認できます。

### 処理の流れ

1. `StoreMapper`：ARCore から自己位置と生深度を取得し、約 2.5m 単位の区画に分ける
2. `DepthFusion` / `VoxelGrid`：深度を 3D の点に戻し、5cm 単位で統合する（2 回以上観測された点だけを地図に残す）
3. `MapRenderer`：点群、歩いた軌跡、現在地を描画する

各区画は ARCore の Anchor に結びつけているため、歩行中に ARCore が位置を補正しても区画ごと追従します。

### 人と壁の判別

胸に固定したカメラで、正面にあるものを判定して画面に表示します。

1. `MediaPipePersonDetector`：カメラ画像から人を検出する
2. `PersonDistance` / `PersonTracker`：人の距離と 3D 位置を求め、位置の変化から「止まっている」「向かってくる」などを判定する
3. `ObstacleClassifier`：人以外の正面の深度を 3D の点に戻し、縦の平面に並ぶなら壁、それ以外なら物とする。データが足りないときは「確認できません」と表示する

検出した人は 3D 地図の上に、動きごとに色分けした柱としてリアルタイムの位置で表示します。距離が分からない人は地図に置けないので、人数だけを表示します。

### 手と指の認識

`MediaPipeHandDetector` で手の 21 点を読み取り、`HandAnalysis` で左右、形（指さしなど）、指の向き、手のひらの向き、距離、指先のワールド座標を求めます。人として検出された枠が手で大きく占められている場合は、`OwnHandFilter` で自分の手や腕の誤認として除外します。

### 使用技術

- ARCore（位置追跡、Depth API）、OpenGL ES
- MediaPipe Object Detector（EfficientDet-Lite0）、Hand Landmarker（いずれも端末内で実行）
- Kotlin / Jetpack Compose

商品の判別（Gemma 4 / LiteRT-LM）のコードは `vision` パッケージなどにありますが、今は使っていません。地図へのラベル付けを実装するときに接続します。

### 動かし方

ARCore と Depth API に対応した実機が必要です。

```
./gradlew :app:installDebug
```

起動して端末を左右に動かすと記録が始まります。店内を歩いたあと「地図を見る」を押すと、1 本指で回転、2 本指で移動と拡大ができます。地図はまだ保存されず、アプリを終了すると消えます。

  ## 開発用のリポジトリは別に作ることをおすすめします

  このリポジトリでは **GitHub Actions と GitHub Pages が使えません**。CI やデプロイ、Pages での公開をしたいときは、チームで開発用のリポジトリを別に作ってください。

  - 開発用のリポジトリは、チームのメンバーのアカウントや、チームで作った Organization に作ってください
  - 開発はそちらで進めて、提出期限までに最終版のコードと資料をこのリポジトリに push してください
  - 審査はこのリポジトリの内容で行います。開発用のリポジトリにしかないものは、審査の対象になりません
  - デプロイした作品の URL があれば、この README に書いてください

  ## 秘密情報をコミットしない

  API キー・パスワード・サービスアカウントの鍵などは、**絶対にコミットしないでください**。公開リポジトリなので、push
  した時点で誰でも見られます。開発用のリポジトリから持ってくるときも、履歴ごと push すると、過去のコミットに含まれる秘密情報も公開されます。

  - 秘密情報は `.env` や `.dev.vars` などに書き、コミットしない（`.gitignore` に入れてあります）
  - 誤って push したら、すぐにキー（鍵）を無効にして作り直し、運営に連絡してください。履歴から消すだけでは不十分です
  - GitHub の push protection が、よく知られた形式のキーの push を止めることがあります。止められたら、そのキーをコミットから外してください
